Política de privacidad de Home Launcher

Última actualización: 18 de noviembre de 2026

Home Launcher sustituye la página de nueva pestaña por un launcher visual personalizable. Esta política explica cómo se tratan los datos dentro de la extensión.

Datos que trata la extensión

La extensión permite introducir nombres y direcciones de sitios web, organizar accesos y carpetas, seleccionar imágenes para iconos o fondos y modificar preferencias visuales. Esta información se procesa únicamente para proporcionar las funciones visibles de la extensión.

Almacenamiento local

Los accesos, carpetas y preferencias se guardan mediante chrome.storage.local. Las imágenes personalizadas se guardan en IndexedDB dentro del perfil local del navegador. El usuario puede exportar voluntariamente una copia de seguridad a un archivo local.

Opcionalmente, el usuario puede activar copias diarias completas en una carpeta local que selecciona y autoriza. La extensión recuerda el acceso a esa carpeta y la fecha de la última copia en IndexedDB, sin transmitirlos. Solo escribe sus archivos de copia; no examina otros documentos ni elimina copias anteriores. Los archivos externos permanecen al desinstalar y el usuario puede desactivar la función o eliminarlos manualmente.

Recopilación y transmisión

El desarrollador no recopila, recibe ni almacena datos personales, accesos, imágenes, búsquedas, historial o preferencias. La extensión no utiliza analítica, publicidad, cuentas de usuario ni servidores del desarrollador.

Las búsquedas se envían al motor predeterminado de Chrome mediante chrome.search. Si un favicon no está en la caché interna de Chrome, el navegador puede solicitarlo directamente al sitio añadido por el usuario. El desarrollador no recibe estas comunicaciones.

Compartición y venta

El desarrollador no vende, comparte ni utiliza datos para publicidad, perfilado, evaluación crediticia o finalidades distintas de las funciones descritas.

Control del usuario

El usuario puede editar o eliminar sus accesos, carpetas e imágenes, restaurar los valores iniciales o desinstalar la extensión.

Seguridad

Home Launcher utiliza Manifest V3, no ejecuta código remoto y solicita únicamente permisos de almacenamiento local, favicons y búsqueda con el proveedor predeterminado.
